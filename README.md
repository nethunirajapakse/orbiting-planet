# 🌌 Orbiting Planet (Three.js 3D Animation)

<img width="1354" height="629" alt="Screenshot 2026-05-25 014457" src="https://github.com/user-attachments/assets/c1c84c07-355d-4956-b9c0-225be339ac65" />

A visually immersive 3D animation project showcasing an interactive astronomical scene built using **Three.js**, **WebGL**, and **Vite**. This project explores responsive 3D graphics, smooth orbit animations, and realistic material rendering in the browser.

---

## 🚀 Features

* **Interactive 3D Scene:** Real-time WebGL rendering with camera controls (zoom, pan, rotate).
* **Dynamic Orbit Animations:** Realistic mathematical pathing for orbiting bodies.
* **Realistic Lighting & Materials:** Implementation of ambient, directional, or point lighting to create depth and shadows.
* **Optimized Performance:** Built on top of Vite for lightning-fast hot module replacement (HMR) and production bundling.

---

## 🛠️ Tech Stack

* **Core:** [Three.js](https://threejs.org/) (WebGL 3D Engine)
* **Build Tool / Dev Server:** [Vite](https://vitejs.dev/)
* **Language:** JavaScript (ES6+)

## 📦 Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
```bash
git clone git@github.com:nethunirajapakse/orbiting-planet.git

```


2. **Navigate into the project directory:**
```bash
cd orbiting-planet

```


3. **Install the dependencies:**
```bash
npm install

```



### Development

To start the local development server with hot-reloading:

```bash
npm run dev

```

Once running, open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173/`).
